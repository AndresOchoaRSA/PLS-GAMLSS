## PLS-GAMLSS (Flexible Partial Least Squares with GAMLSS models)

This repository contains the necessary elements to reproduce the results of the manuscript "Flexible Partial Least Squares with GAMLSS models".

pls_gamlss() is a function in R that allows fitting a PLS-GAMLSS model using several distributions.

Repository: https://github.com/AndresOchoaRSA/PLS-GAMLSS
